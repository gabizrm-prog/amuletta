# Amuletta

Protótipo de e-commerce para uma marca fictícia de acessórios, em vermelho e branco: página inicial com hero, categorias, catálogo filtrável, benefícios, newsletter e rodapé.

**Ver online:** https://gabizrm-prog.github.io/amuletta/

## Funcionalidades

- Filtro por categoria (pílulas, círculos de categoria e menu)
- Busca por nome, ordenação (mais vendidos, novidades, menor/maior preço)
- Adicionar à sacola com contador e favoritos
- Layout responsivo (desktop e mobile)

## Tecnologias

HTML, CSS e JavaScript puros, sem dependências. Fontes: Cormorant Garamond e Manrope (Google Fonts).
